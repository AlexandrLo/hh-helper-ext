# Proposal

## Why

Расширение сейчас ставится только временно, через `about:debugging`: оно слетает при каждом перезапуске Zen/Firefox, а `.xpi` приходится собирать локально. У него нет иконки, поэтому в `about:addons` и меню расширений оно выглядит как безымянная заглушка. Нужна подписанная сборка, которая ставится навсегда, публикуется автоматически и сама обновляется.

## What Changes

- Иконка расширения: белые «hhh» на красном фоне, одна векторная картинка на все размеры. Буквы нарисованы контурами, без зависимости от шрифтов системы.
- Единый источник версии: `package.json`. Поле `version` убирается из `src/manifest.json`, сборка подставляет его в `dist/manifest.json`.
- **BREAKING** gecko id меняется с `hh-helper-ext@local` на `hh-helper-ext@alexandrlo.github.io`. Постоянно установленных копий нет, ломается только временная установка: её нужно удалить и поставить расширение заново.
- В манифест добавляется `update_url`, указывающий на `updates.json` последнего GitHub-релиза.
- GitHub Actions на каждый push в `main`: тесты, typecheck, lint. Если релиза `v<version>` ещё нет: сборка, подпись в AMO (канал unlisted), GitHub-релиз с подписанным `.xpi` и `updates.json`.
- README: установка из релиза, автообновление, порядок выпуска новой версии, настройка секретов AMO.

## Capabilities

### New Capabilities
- `extension-icon`: как расширение выглядит в интерфейсе браузера (иконка в `about:addons` и меню расширений).
- `signed-releases`: автоматический выпуск подписанных версий расширения на GitHub и их автообновление в браузере.

### Modified Capabilities

Нет. Поведение на страницах hh.ru (`vacancy-response-counters`) не меняется.

## Impact

- Код: `src/manifest.json`, `scripts/build.ts`, новый `src/icons/icon.svg`, новый `.github/workflows/release.yml`, `README.md`.
- Внешние системы: аккаунт разработчика на addons.mozilla.org, API-ключ в секретах репозитория (`AMO_JWT_ISSUER`, `AMO_JWT_SECRET`), GitHub Releases репозитория `AlexandrLo/hh-helper-ext`.
- Новых npm-зависимостей нет: подпись делает уже установленный `web-ext`, релиз создаёт `gh` на раннере.
- Пользователь: временную установку с id `@local` нужно один раз удалить и поставить подписанный `.xpi` из релиза.
