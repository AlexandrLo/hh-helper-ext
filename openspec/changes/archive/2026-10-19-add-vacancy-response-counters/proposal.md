# Proposal

## Why

На hh.ru в вебе не видно, сколько откликов уже собрала вакансия, хотя мобильное приложение это число показывает. Без него трудно оценить конкуренцию до отклика. Исследование показало, что сайт уже присылает браузеру счётчики откликов во внутреннем состоянии страницы, но не отображает их. Значит, их можно показать без API, токенов и дополнительных запросов.

## What Changes

- Новое Firefox-расширение (WebExtension, MV3, TypeScript) для локальной установки через `about:debugging` или `web-ext`. Публикация в AMO не планируется.
- На странице поиска (`hh.ru/search/vacancy*`) у каждой карточки вакансии выводятся поля `responsesCount` и `totalResponsesCount`, в том числе после SPA-переходов (пагинация, фильтры) и после догрузки карточек.
- На странице вакансии (`hh.ru/vacancy/<id>`) выводятся поля `vacancyResponsesCount` и `totalResponsesCount`.
- Поля выводятся под своими исходными именами, без переименования и интерпретации, потому что их смысл пока установлен только по наблюдениям.
- Данные берутся только из того, что сайт сам отдаёт браузеру на текущей странице: из встроенного начального состояния и из ответов SPA-запросов сайта. Между страницами ничего не сохраняется. Расширение не делает собственных сетевых запросов, не обращается к `api.hh.ru`, не хранит токенов и секретов.
- Если данных нет или их формат изменился, расширение ничего не показывает и не мешает странице.
- Расширение только читает. Никаких откликов и других действий от имени пользователя.

Отклонено по итогам исследования: получение данных через API hh от имени Android-клиента. Без токена API отвечает `403`. Токен приложения через `client_credentials` общий для всех и отзывается при каждом повторном запросе. У одиночной вакансии в API счётчиков нет. Порядок выдачи сайта через API не воспроизвести.

## Capabilities

### New Capabilities
- `vacancy-response-counters`: вывод полей счётчиков откликов, которые hh.ru уже передал браузеру, на страницах поиска и вакансии, и поведение при отсутствии данных.

## Impact

- Новый проект с нуля: `manifest.json`, исходники TypeScript, сборка через esbuild, тесты через встроенный `node --test`.
- Разрешения Firefox: `webRequest`, `webRequestBlocking`, `webRequestFilterResponse`, хост `https://hh.ru/*`. Разрешение `storage` не нужно.
- Зависимость от недокументированных полей фронтенда hh.ru (`HH-Lux-InitialState`, `responsesCount`, `totalResponsesCount`, `vacancyResponsesCount`, атрибуты `data-qa`). Сайт может изменить их в любой момент.
- Внешние системы не затрагиваются: нагрузка на hh.ru не растёт.
